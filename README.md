# Практична робота № 1
## Проєктування інтерактивного UI-компонента у Figma, семантична реалізація та валідація доступності (a11y)

### Використані технології

- HTML5 — семантична структура компонента.
- CSS3 — оформлення, адаптивний дизайн і стани взаємодії.
- JavaScript — обробка натискань, таймер і керування прогресом.
- Figma — проєктування UI-компонента та його станів.
- Google Lighthouse — перевірка якості вебінтерфейсу.

### Реалізовані вимоги

- Використано семантичний елемент `<article>`.
- Для керування застосовано кнопку з типом `button`.
- Додано ARIA-атрибути для доступності.
- Реалізовано стани компонента Play/Pause.
- Передбачено адаптивність для різних розмірів екрана.
- Додано видимий індикатор клавіатурного фокусу.
- Використано CSS-змінні для кольорів інтерфейсу.
